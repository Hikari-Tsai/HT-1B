# S6＋可微分電路（S6-DiffCircuit）架構設計

日期：2026-11-10　狀態：設計稿，尚未實作
前因：`2026-11-06-pinn-generalization-experiments.md` 的 P1 結果與爆衝檔診斷。

## 1. 要解決的問題

P1 顯示目前的 S6＋PINN 在沒訓練過的 Threshold −40 dB 上壓縮不足 5–7 dB，比 S6 更容易爆衝。診斷找到原因：

- e/f/s 由網路**直接預測**，物理只是**訓練時**的殘差懲罰。推論時沒有任何東西強迫狀態遵守電路，所以「Threshold 降低 → 偵測電壓 e 變大」這件事要靠網路從資料學；沒看過的 Threshold，網路就不會做。
- 物理殘差在留出檔升高 20–30 倍，代表電路「知道」狀態錯了，但沒有機制把它拉回來。
- 電路參數漂移很大且每個 seed 不同，參數不再代表真實電路。

同一套電路公式在看過 −40 dB 的模型上幾乎完美（電平誤差 0.2 dB），所以公式本身可用；問題在物理沒有參與推論。

## 2. 設計原則

1. **狀態由電路積分，不由網路預測。** e/f/s 每一步都由電路的狀態方程從上一步算出（硬約束）。旋鈕，尤其 Threshold，只經由電路公式（`taper(threshold)`、`ratio_pot·ratio`、attack／release 電阻）影響狀態，所以外插行為由物理決定。
2. **網路只做有界修正，而且看不到旋鈕。** 網路（S6/TFiLM）負責電路沒建模的部分：側鏈頻率響應、時間常數的誤差、輸出端音色。主要版本的修正量只依音訊計算、不接收旋鈕標籤，因此無法學出「只對訓練過的 Threshold 有效」的捷徑。所有修正都限制在小範圍內（見第 3 節），不能蓋過物理。
3. **旋鈕對電路的映射用少數可學的物理參數表示。** 例如 Threshold 電位器的對數 taper 目前是假設值（`pot_taper=2`，硬體未知），改成可學的單一參數。低維、單調的物理映射外插時遠比網路穩定。
4. **電路參數保持可辨識。** 先驗權重提高，並以「3 個 seed 學到的參數是否一致」作為檢查項目。
5. **不再需要物理殘差 loss。** 狀態本來就滿足電路方程，loss 只有音訊項（L1、ESR、頻譜，與 S6 相同）。嚴格來說這是「可微分物理混合模型」，不是殘差型 PINN；報告中會這樣稱呼。

## 3. 架構

```
Dry ──┬─────────────────────────────► 前端被動網路（含 GRE 導通量 G(t)）──► 後級放大 tanh ──► × 輸出修正 ──► Wet
      │                                          ▲
      │      偵測器：rect_gain·|front_a|·taper(thr; θ)·exp(δ_det)           │
      │                     │                                                 │
      │                     ▼                                                 │
      │      C3 狀態 e：充電 ra·exp(δ_att)、放電 rth·exp(δ_rel)              │
      │                     │                                                 │
      │                     ▼                                                 │
      │      GRE 快／慢 f, s：一階指數更新 ───────────────► G = dark + span·(mix·f + (1−mix)·s)
      │
      └──► S6/TFiLM（只看音訊）──► δ_det, δ_att, δ_rel, δ_out, r_out（全部有界）
```

**網路修正（全部 tanh 有界）：**

| 修正 | 作用 | 範圍 | 對應的未建模效應 |
|---|---|---|---|
| δ_det | 偵測器增益乘上 exp(δ) | ±0.5（約 ±4 dB） | 側鏈頻率加權、整流器非理想 |
| δ_att、δ_rel | 充電、放電時間常數乘上 exp(δ) | ±1 | 二極體與 RC 的誤差、程式相依的釋放 |
| δ_out | 輸出增益乘上 exp(δ) | ±0.25（約 ±2 dB） | 後級增益誤差 |
| r_out | 輸出加上小殘差 | 0.05·tanh | 後級音色 |

**可學的物理參數：** 現有 7 個（`gre_span`、`gre_half`、四個 GRE 時間常數、`amp_gain`），加上 `pot_taper`（Threshold 電位器律）、`rectifier_gain`、`rectifier_offset`。先驗權重從 1e-4 提高到 1e-2，再依第 6 節的 G3 結果調整。

## 4. 電路積分器

C3 迴路很硬：opamp 增益 1000，在追蹤區的等效時間常數約 2.7 µs，所以現有求解器在每個樣本用隱式 backward Euler 加 Newton 求解。這種寫法無法直接放進 GPU 批次訓練，因此改用以下近似：

- **控制路徑降頻：** e/f/s 每 R 個樣本（R = 8 或 16，即 6 kHz 或 3 kHz）更新一次。偵測器取該區塊 |front_a| 的峰值；導通量 G 以線性內插回 48 kHz，供音訊路徑使用。GRE 最快的時間常數是 1 ms，內插誤差小。
- **C3 充電：**
  - 當偵測器高於 e 超過 13.5 mV 時，opamp 飽和在 rail 上，充電電流 (rail − e − 0.55)/ra 不硬，時間常數 ra·C3 ≥ 2.74 ms，可以顯式更新。
  - 進入追蹤區後，高增益迴路讓 e 停在 e* = (1000·det − 0.55)/1001 附近，以「不超過 e*」的夾限取代隱式求解。
- **C3 放電：** 時間常數約 0.1–0.4 s，可以顯式更新。
- **GRE：** 用指數積分 f ← target + (f − target)·exp(−dt/τ)，攻擊與釋放的 τ 依方向選擇。無條件穩定。
- **時間截斷：** 狀態跨 chunk 延續，在 chunk 邊界 detach，與現行 TBPTT 相同。暖機段完整積分 Dry，不再從零狀態硬接。
- **實作路線：**
  - v1：PyTorch 迴圈。R = 16 時每個 chunk 只有 64 步，以 CUDA graph 加速。
  - v2：速度不夠時改寫成 Triton kernel（前向加重算式反向），比照現有的 fused scan。

## 5. 比較組（T40 留出，seed 7、8、9）

| 代號 | 內容 | 作用 |
|---|---|---|
| M-S6 | 既有 S6 有界 gain；補跑 seed 9 | 純資料基準，沿用 P1 的 seed 7、8 |
| M-CIRC | 只有積分電路與可學參數，沒有網路 | 純物理能外插到哪裡；只有約 10 個參數，訓練 5 輪即可 |
| M-HYB | 第 3 節完整設計，修正量只看音訊 | 主要候選 |
| M-HYB-K | 同 M-HYB，但修正量也接收旋鈕標籤 | 消融：旋鈕條件化的修正是否破壞外插 |

既有的 M-PINN、M-STRUCT 不再重跑，P1 結果直接引用。

**主要指標（沿用 P1）：** 留出檔逐檔 log(ESR_HYB) − log(ESR_S6)，取中位數。

**預先固定的判定：**
- **H1′ 成立的條件：**
  1. 3 個 seed 的中位數都 < 0；
  2. 合併後以檔案 bootstrap、在訓練內分層的 95% 區間不含 0；
  3. 留出檔 ESR＞1 的檔數不多於 M-S6。
- **在已訓練組合上的代價：** M-HYB 的 macro ESR 與 M-S6 的比值照實報告，不作為通過條件。混合模型在分布內可能較差，這是預期中的取捨。
- **機制檢查：**
  - 留出檔的 e 最大值應接近全資料 PINN 或真實電路（約 0.37–0.38），不應停在 −30 dB 的水準。
  - 電平誤差應小於 2 dB。
  - 這兩項用來確認改善來自設計的機制，而不是巧合。
- **M-HYB 對 M-HYB-K：** 如果 K 版在留出檔上明顯較差，就支持原則 2。

## 9. 風險與誠實的限制

- **電路結構誤差：** 電路本身有結構誤差。即使用全部組合擬合（GRU＋PINN 參數），在 −40 dB 的 ESR 仍是 0.39，高於留出 S6 的 0.31。如果有界修正補不回這段差距，M-HYB 的留出分數可能「外插穩定但整體偏高」。M-CIRC 可以先量出這個下限。
- **Threshold 律不確定：** 硬體的 Threshold 電位器律未知。如果真實律不是單一對數 taper，可學的 `pot_taper` 會外插錯誤；那時再考慮二參數的單調律。
- **降頻偵測器：** 降頻後的峰值偵測對極短暫態（< R 個樣本）的反應較慢。G1 會量化這個誤差。
- **只是一種留出方案：** T40 只是一種留出；成立後仍需 K1–K3、A0 才能談「泛化」。

## 10. 評估過的替代方案：PhysicsNeMo FNO

伺服器上的 PhysicsNeMo 2.2.2 有 `physicsnemo.models.fno.FNO`（支援 `dimension=1`）。

**直接以 FNO 做 Dry→Wet（旋鈕作為輸入通道）：不建議。**
- **沒有解決根因：** 旋鈕仍是網路輸入，沒看過的 Threshold 一樣是分布外輸入，外插問題與 S6 相同。加上物理殘差（PINO）仍是軟約束，正是 P1 的失敗模式。
- **頻寬：** FNO 截斷到少數低頻模態（預設 16），48 kHz 音訊需要全頻寬，等於低通。
- **非因果、視窗固定：** FNO 是全域傅立葉運算，會用到未來樣本，不能即時處理。長 Release（0.5 s 以上）的記憶需要很長的視窗，跨視窗的狀態延續也不自然。

**FNO 可能有用的位置：**
- **控制速率的增益包絡：** 偵測器包絡 → e/f/s 或增益軌跡是平滑的低頻訊號，適合 FNO 的低模態表示，但仍有非因果的限制。
- **電路的平行代理模型：** 用電路求解器產生大量模擬資料，涵蓋所有旋鈕值，包括 −40 dB；以 FNO 學「偵測器包絡＋旋鈕 → 狀態軌跡」，取代第 4 節的逐步積分以換取平行速度。物理知識經由模擬資料涵蓋沒錄過的設定。代價：
  - 會繼承電路的結構誤差（全資料擬合仍有 ESR 0.39）。
  - 代理模型在攻擊與釋放切換、`max` 等不連續處的誤差需要另外驗證。
  - 列為 G2 速度不通過時的備案，與 v2 Triton kernel 並列。
