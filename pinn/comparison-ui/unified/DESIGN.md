# 六模型結果頁整理

使用者要求全面整理既有頁面、六模型一起比較、檢視缺少新測試的內容並刪除重複段落。

保留米白底、炭灰文字、綠色重點，以及 Bahnschrift／Segoe UI／Microsoft JhengHei 字型。採研究報告布局：短標題、評估範圍、唯一主表、可展開的逐檔和訓練紀錄、唯一方法說明。

主表同時呈現七方法的五指標，選定欄位排序六模型；基準固定在表尾，避免把七方法誤稱為七個模型。每欄粗體表示六模型內最小值，不含基準。數值附真實比例的輔助細條，不另做重複圖表。

舊頁的局部完整測試、五段試聽／盲測和各模型獨立摘要從主頁移除，原始資料保留。歷史完整區段測試只顯示覆蓋狀態，避免被誤認為新模型都已測過。這次未產生新測試分數。

鍵盤操作使用原生 select/button/details；窄螢幕重排工具列，資料表可水平捲動。數值、匯出、空狀態、主題失敗回退納入 Node 檢查。未進行瀏覽器視覺驗收。

後續擴充沿用相同訓練切換區塊，加入 MLP／GRU 的既有步數紀錄。單批訓練 loss 與每輪驗證 ESR 分別標示；一輪完整走訪的最終參數不標為經多輪選出的最佳 checkpoint。較長的步數表每頁 20 筆，完整紀錄可匯出 CSV。
