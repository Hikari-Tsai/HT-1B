先完整讀取 Dry 歷史，再計分

電路、S4、S6、S6＋PINN 從錄音第 0 個樣本開始連續推論，跨計分片段保留狀態；沒有用 Wet 初始化。RiccardoVib 按其原生設計，每 16 個輸出樣本帶入前 16 個 Dry 樣本。尾端補齊 S4 的區塊後丟棄補零輸出。

固定原權重與電路參數；不重訓、不用新成績挑 checkpoint、不擬合增益或延遲。長片段 MR-STFT 使用 512／1,024／2,048；歷史短視窗是 256／512／1,024，兩者分數不直接相比。

資料怎麼切、視窗怎麼計分 ＋

依聲音內容分組

620 個 48 kHz 雙聲道 WAV，左 Dry、右 Wet。以 Dry 的音色變化與重複內容分組，同一素材群在不同旋鈕錄音中共用切分；不是隨機分檔。

共同時間軸的 90–107.7 秒、149.4–160 秒為驗證；199.7 秒至檔尾為測試，其餘訓練。一個錄音的邊界校正提前 0.75 秒。素材群由聲學推定，未經歌曲／演奏者標籤確認。

歷史短視窗規格

每檔兩個驗證區段，各取中央 5,120 樣本。前 4,096 樣本（85.33 ms）提供 Dry 歷史，後 1,024 樣本計分；共 1,269,760 個評分樣本。RiccardoVib 使用其原生 16 樣本歷史。

其他方法逐視窗重設內部狀態，再以 Dry 暖機。沒有額外輸出增益擬合或延遲校正；短暖機不足以代表完整 Attack／長 Release 行為。

五種誤差如何閱讀 ＋

ESR

誤差能量／目標能量。分母下限為 N × 10⁻⁸；0.1 代表約 10% 能量比，不代表 90% 準確率。安靜素材可能產生較高相對誤差。

MSE

逐樣本差值平方的平均，保留原始振幅，對大的瞬間誤差較敏感。

MAE

逐樣本絕對差的平均；比 MSE 較不受少數巨大誤差主導。

MR-STFT

長片段 FFT 512／1,024／2,048；歷史短視窗 FFT 256／512／1,024。hop 為 1/4，periodic Hann、置中反射 padding。各解析度的頻譜收斂誤差＋log magnitude L1，再等權平均；不是百分比。

RMS 包絡誤差

10 ms 格點的 RMS 電平絕對差，單位 dB，下限 −100 dBFS；尾格按樣本數加權。

兩種彙整方式

逐檔平均讓每檔等權；合併 ESR 先加總誤差與目標能量再相除。其他合併指標依樣本數加權，不串接不連續片段。全部越低越好。

PINN、來源與本次整理紀錄 ＋

PINN 的比較限制

S6＋TFiLM＋PINN 預測 e／f／s，再由電路公式輸出；共用 C3 電流平衡與快、慢光學狀態約束。原 S6 直接學增益，本次同時變更輸出端與 loss，不能當成只增加物理 loss 的單變因比較。

MLP／GRU 的展示結果是學得參數後的數值求解；S6＋PINN 則直接使用網路預測的物理狀態。
