純演算法：未經資料擬合的原始電路參數，直接數值求解。
MLP＋PINN：全資料訓練後辨識的電路參數，以數值求解器輸出。

相同樣本與歷史

沿用 620 檔的每檔 2 個驗證區段，各取中央視窗。每視窗共 5,120 樣本，前 4,096 樣本（85.33 ms）只提供 Dry 歷史，後 1,024 樣本評分；共 1,269,760 個評分樣本。

純演算法、MLP／GRU 電路與 S4／S6 都逐視窗重設狀態。RiccardoVib 按原生區塊使用前 16 樣本。沒有輸出增益擬合或延遲校正。短暖機與短評分視窗不足以代表長時間 Release 行為。

五項指標的定義

ESR = Σ誤差² / max(ΣWet², N × 10⁻⁸)；MSE 與 MAE 維持原振幅。逐檔平均讓 620 檔等權；合併 ESR 先累加誤差能量與目標能量，所以兩者可能明顯不同。

MR-STFT 使用適合此短視窗的 256／512／1,024 FFT、1/4 hop、periodic Hann、反射置中 padding，平均頻譜收斂誤差與 log magnitude L1。RMS 包絡為 10 ms 視窗、−100 dBFS 下限。頻譜／包絡在合併模式依樣本數加權，不串接不連續片段。

如何解讀比較

MLP／GRU 曾完整走訪 51 億訓練樣本；S4／S6 每輪只取各訓練區段的代表視窗，RiccardoVib 的原始訓練範圍未完全確認。相同評分條件不等於相同訓練預算。

驗證集曾用來選模，因此不是新的獨立測試。以下歷史實驗使用較長片段或完整 Dry 歷史，應在各自區塊內解讀；五模型＋純演算法全部來自這次共同評估。

同一份輸入，同一段評分

5 段 48 kHz 音訊使用共同樣本區間 [16, 95984)，每段 95,968 個樣本。所有模型不額外擬合輸出增益或時間偏移。各段獨立計分，再取算術平均。

ESR = Σ(預測 − Wet)² / ΣWet²。MSE = 平均平方誤差。MAE = 平均絕對誤差。ESR 無單位，MSE 為振幅平方，MAE 為振幅；皆越低越好。

Attack / Release 顯示資料集的旋鈕刻度，並非毫秒或秒。Threshold 使用負 dB；本組 Gain 均為 0。

三條不同的建模路徑

純演算法：未經本次擬合的物理電路參數，直接數值求解。

PhysicsNeMo：PINN 從我們的 20 段訓練資料前綴辨識物理參數，再由數值求解器輸出新音訊。圖表評的是部署用求解結果，不是 PINN 的錄音軌跡重建。

RiccardoVib：條件式 Encoder–Decoder 模型，以固定權重直接推論。原生 TensorFlow 與 Torch 移植在 128 個區塊的最大差異為 。訓練與 RiccardoVib 模型的 GPU 推論使用 RTX 5060 Ti；數值求解使用 CPU。

如何解讀這個排名

RiccardoVib 的訓練集與訓練量和我們不同，也可能包含這些錄音，因此不是獨立的泛化測試。5 段短片段無法代表整首音樂、所有旋鈕設定或長時間壓縮記憶。

RiccardoVib 的前處理未完整附在模型資料中；條件順序與 Threshold 方向經我們的 20 段訓練資料校準，未使用此處 5 段驗證資料。最佳 checkpoint 使用此驗證集選擇，仍需額外獨立測試。

新增指標的明確定義

MR-STFT：FFT／視窗為 512、1,024、2,048 samples，hop 為 128、256、512。使用 periodic Hann、置中反射 padding、未正規化 FFT。每解析度計算頻譜收斂誤差 ||P−T||F / ||T||F ＋平均 |ln P−ln T|，再等權平均。P、T 為振幅頻譜，平方振幅下限 1e−8。

RMS 包絡 MAE：10 ms 不重疊視窗，最後一格使用剩餘樣本；RMS 轉 dBFS，下限 −100 dBFS。預測與 Wet 的絕對 dB 差以每格樣本數加權平均，不額外匹配音量。

這是本頁固定的評估規格，並非兩篇論文數字的直接重現。MR-STFT、包絡誤差均越低越好；頻谱誤差不測相位，應與時域指標一起看。
